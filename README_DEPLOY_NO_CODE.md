# AirDesign Landing Page - Vercel Fixed

Đây là bộ project đầy đủ để upload lên GitHub và deploy Vercel.

## Cấu hình Vercel

- Framework Preset: Vite
- Build Command: npm run build
- Output Directory: dist
- Install Command: npm install

## Cách upload

Không upload file ZIP trực tiếp lên Vercel. Hãy giải nén, rồi upload toàn bộ file bên trong thư mục này lên GitHub.
